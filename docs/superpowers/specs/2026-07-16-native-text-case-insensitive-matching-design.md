# Native Text 英文大小写不敏感匹配设计

## 目标

Native Text 广告关键词匹配忽略所有英文字母的大小写。例如接口返回关键词 `OLAY` 时，AI 回答中的 `olay`、`Olay` 和 `OLAY` 均可被渲染为广告链接。

## 行为约束

- 关键词与候选文本统一转为小写后查找匹配位置。
- 链接文字保留 AI 回答中的原始大小写，不使用接口关键词覆盖原文。
- 继续跳过已有链接、代码块、预格式化文本、脚本和样式节点。
- 链接跳转继续使用 `landing_url`。
- 点击上报继续使用 `click_tracking_url`。
- 锚点去重与曝光上报行为保持不变。

## 实现范围

仅修改 `injectNativeTextAnchor` 的关键词定位逻辑：使用小写副本计算索引，再用该索引切分原始文本节点。其他广告协议、状态管理和渲染结构不变。

## 验证

- 新增回归测试：关键词 `OLAY` 能匹配原文 `olay`。
- 断言生成的链接文字仍为原文 `olay`。
